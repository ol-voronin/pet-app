# AGENTS.md — вход для любых агентов (Antigravity, VS Code, Codex и другие)

Этот файл читают инструменты, которые не знают про `CLAUDE.md`. Правила проекта одни для всех:

1. Прочитай `CLAUDE.md` целиком — стек, команды, правила кода, доменные правила, ограничения владельца. Они
   обязательны для тебя так же, как для Claude Code.
2. Прочитай `docs/TEAM.md` — в проекте работает команда агентов с общей очередью задач в GitHub.
3. Перед работой: `git fetch origin main`, затем `HANDOFF.md` и `docs/LESSONS.md`.

## Ты — гость команды

- **Подпись.** Каждый комментарий в GitHub начинай с подписи инструмента: `**[agy]**` для Antigravity,
  `**[vscode]**` для агента в VS Code. Комментарий `ol-voronin` без подписи — слово владельца.
- **Задачи** бери только из очереди: issue с метками `task` + `ready` без `in-progress` и `needs-owner`, начиная с `bug`.
  Сначала заявка: метка `in-progress` и комментарий «беру» с именем ветки. Занятое не бери.
- **Одна задача — одна ветка — один PR** в `main`, с `Closes #N` и описанием «что сделано · как проверить · что не вошло».
  До PR: `pnpm typecheck && pnpm lint && pnpm test`.
- **Свой PR не вливай.** Его разбирает ревьюер команды (`**[reviewer]**`) и вливает сам. На находки отвечай по существу:
  исправил (коммит) или не согласен (почему).
- **Решения владельца** — issue с меткой `decision` (варианты, цена каждого, рекомендация), а не вопрос в чате и не
  молчаливый выбор. Список «Всегда к владельцу» — в `docs/TEAM.md`.
- **Не трогай** чужие открытые PR и ветки, `.env*`, продакшн-базу (ветка Neon `main`), настройки сторов и подписок.
- **Ничего платного** не подключай. Секретов в репозитории, issue и комментариях быть не должно — репозиторий публичный.

GitHub из терминала: `gh` (issue, PR, метки, комментарии). Если `gh` не настроен — скажи владельцу, не обходи.

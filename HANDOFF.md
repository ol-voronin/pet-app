## 1. Что это за продукт
Мобильное приложение B2C + B2B для владельцев животных, старт — Украина (город-плацдарм — Харьков).
- **Медкарта питомца:** прививки, обработки, визиты, анализы, лекарства; скан документов с AI-распознаванием и загрузка файлов как есть; напоминания; история.
- **Карта:** ветклиники, ветаптеки, площадки для выгула, свои метки пользователя.
- **События и B2B** (клиники, аптеки, организаторы) — после MVP.

Позиционирование: «Паспорт здоровья и город для вашего питомца. Ваша медицинская история — бесплатна навсегда, в любой клинике».

Названия у продукта пока нет. Рабочее имя в коде — `pet-app`.

## 3. Ключевые выводы исследования (без изменений)
- **Ниша свободна:** никто в Украине не объединяет медкарту с AI-распознаванием, карту и события.
- **Главный конкурент — JetVetPass** (ТОВ «Джетвет», Харьков): 50K+ установок, рейтинг 3.0, около 4K MAU. Медкарта приходит из клиник на JetVet CRM. Слабость — пейвол на историю.
- **Урок рынка:** JetVetPass и 11pets получили волну негатива, закрыв накопленные данные пейволом. **Историю не блокировать никогда.**
- **Рынок:** 17,7 млн животных (7,1 млн котов, 4,5 млн собак).
- **Госреестр животных** даст базовый паспорт, а не медкарту. Хранить номер чипа и номер реестра.

Монетизация — как в `docs/PRD.md`: Free навсегда + 5 AI-сканов в месяц; Plus и B2B — во второй версии.

## 4. Решения по продукту от 19.11.2026
Полные формулировки — в `docs/PRD.md`. Коротко:
1. **Онбординг.** Вход по телефону → «Добавьте питомца» с двумя равными путями: скан ветпаспорта или ручная форма (кличка, вид, дата рождения). Скан не обязателен.
2. **Кнопка «+» в медкарте.** Только добавление: скан, загрузка файла, прививка, обработка, визит, анализ, лекарство, вес/заметка, напоминание.
3. **Произвольные напоминания.** Груминг, когти, корм, визит, своё — с повтором. Не привязаны к медзаписи.
4. **Действие в напоминании зависит от типа.** Нужен специалист (прививка, укол, визит, груминг) — «Записаться» + «Уже сделано». Делается дома — «Сделано». «Записаться» в MVP — звонок в клинику или выбор места на карте, затем перенос напоминания на дату записи. Онлайн-записи нет.
5. **Свои метки на карте.** По умолчанию личная (видна владельцу и семье, сразу). Публичная — после модерации.
6. **Документы питомца.** Загрузка фото, PDF и других файлов без распознавания; хранение не входит в лимит сканов.
7. **Аватар питомца.** Нарисованный 3D-аватар по умолчанию и, по желанию, фото; оба хранятся, герой медкарты переключается между ними. В QR-паспорте для врача — фото, если есть.
8. **Навигация MVP.** Три таба: Карта · Питомцы · Профиль. «События» — во второй версии.

## 5. Визуальный язык (черновик, проверяется на макетах)
**Принципы**
- Один цвет бренда на кремовом фоне. Второй цвет — только для предупреждений.
- Один герой на экран (питомец, карта или график), остальное плотное и спокойное.
- Без теней: глубина заливкой. Тень — только у элементов, плавающих над картой.
- Главная кнопка — «пилюля» с нижней гранью 4 px. Второстепенные — плоские.
- В списках иконки одноцветные, без цветных плиток.
- Движение только на событиях: нажатие, шторка, «скан распознан», «напоминание закрыто».
- Геймификация без наказаний: счётчик «Всё вовремя · N месяцев», шкала заполненности паспорта, празднования. Ежедневной серии нет.

**Токены**
| Токен | Значение |
|---|---|
| Цвет бренда | `#B5F04F` — только заливкой под тёмным текстом; белый текст на нём запрещён (контраст 1,4) |
| Основной текст и тёмные кнопки | `#14260F` |
| Тёмный зелёный (мелкий текст, грань кнопки) | `#3F7A12` |
| Фон | `#FAF7F0` |
| Карточка | `#FFFFFF`, без тени |
| Второстепенный текст | `#4A5644` |
| Разделитель | `#E4DFD2` |
| Радиусы | пилюля — действие; 20 — карточка и шторка; 12 — поле ввода |
| Главная кнопка | высота 56, нижняя грань 4 px |
| Заголовок экрана | 34 / 38, начертание 800 |
| Основной текст | 15–16 / 22–24 |
| Строка списка | 64 |
| Шрифт | Geologica (Google Fonts, вариативный) — кандидат, финально не утверждён |

Оттенки подобраны на глаз; пара близка к бренду Wise — перед запуском сдвинуть оттенок. На карте пины делать тёмными, чтобы не сливались с зеленью парков. Язык интерфейса — украинский по умолчанию.

## 6. Аватар питомца
- **Стиль:** фигурки «из шариков» — глянцевые надувные собаки и кошки. Свои персонажи, не копия существующих статуэток.
- **Как собирается:** автоматически по виду и породе, владелец правит в конструкторе. Параметры MVP: уши, морда, шерсть, окрас. Только собака и кошка.
- **Прототип:** `tools/avatar/balloon_pets.py` — скрипт для Blender (`pip install bpy`, проверено на bpy 5.3.0, Python 3.13, рендер на CPU). Одна функция `build()` собирает фигурку из параметров и рендерит PNG с прозрачным фоном; 8 фигурок 420×500 — около 2,5 минуты на 2 ядрах.
- **Известные недостатки прототипа:** собаки со стоячими ушами похожи на зайцев; вид спереди скрывает длину корпуса и хвост (такса неотличима); белый окрас теряется на кремовом фоне; глаза мелкие. Рекомендован ракурс в три четверти.
- **Не решено:** рендер в приложении или готовой картинкой с сервера (предложение — с сервера: проще, работает офлайн, не грузит слабые Android); кто доводит 3D-формы.

## 7. Технические решения
**Принято**
- Модульный монолит на TypeScript; монорепо pnpm + Turborepo.
- Мобильное приложение — Expo (React Native), expo-router, TanStack Query, Zustand.
- PostgreSQL + PostGIS (Neon, EU), Cloudflare R2, Redis/BullMQ (Upstash).
- REST + OpenAPI; B2B-кабинет — Next.js на Vercel (вторая версия).
- Данные карты — OpenStreetMap + ручная проверка (Google Places хранить нельзя).
- Распознавание: мультимодальная LLM со строгой JSON-схемой → нормализация по справочнику → обязательный экран подтверждения.
- Медкарта офлайн; у записей есть `source` (manual / ocr / clinic) и версия.
- Платежи: подписки через RevenueCat; билеты — эквайринг mono / WayForPay / LiqPay; чеки — Checkbox.
- Своё GPS-устройство не делать.

**Открыто (оформить через `/adr`)**

2. PowerSync или своя синхронизация.
3. Провайдер распознавания: Claude, Gemini или Google Document AI.
4. MapLibre + MapTiler или Mapbox.
5. Рендер аватара: в приложении или на сервере.

# CLAUDE.md — Pet App (рабочее название)

Мобильное приложение для владельцев животных в Украине: медкарта питомца с AI-распознаванием
документов, напоминания, карта (ветклиники, аптеки, площадки), события. B2C + B2B.
Подробности: `docs/PRD.md`, `docs/ARCHITECTURE.md`, `docs/DATA_MODEL.md`, `docs/ROADMAP.md`.

**Сначала прочитай `HANDOFF.md` в корне.** В нём решения от 19.11.2026, визуальные токены и раздел 9 —
список расхождений: `DATA_MODEL`, `ROADMAP` и `ARCHITECTURE` отстают от `PRD`. При противоречии прав `PRD.md`,
затем `HANDOFF.md`.

## Стек
- Монорепо: pnpm workspaces + Turborepo
- `apps/mobile` — Expo (React Native, TypeScript), expo-router, TanStack Query, Zustand, expo-sqlite + Drizzle
- `apps/api` — Node + Fastify (или NestJS — см. ADR), REST + OpenAPI, Drizzle ORM, BullMQ
- `apps/web` — Next.js (B2B-кабинет, появится на этапе V2)
- `packages/shared` — zod-схемы, типы, сгенерированный API-клиент
- `packages/db` — схема Drizzle и миграции
- БД: PostgreSQL + PostGIS (Neon), файлы: Cloudflare R2, очередь: Redis (Upstash)

## Команды
- `pnpm install` — зависимости
- `pnpm dev` — всё в режиме разработки
- `pnpm -F mobile start` — Expo dev server (нужен development build, не Expo Go)
- `pnpm -F api dev` — API локально
- `pnpm typecheck` / `pnpm lint` / `pnpm test` — проверки, запускать перед каждым коммитом
- `pnpm -F db generate` / `pnpm -F db migrate` — миграции

## Правила работы
1. **Сначала план.** Для любой фичи больше одного файла — сначала план в режиме Plan, жди подтверждения.
2. **Одна фича — одна ветка — один PR.** Ветки: `feat/<кратко>`, `fix/<кратко>`.
3. **Проверяй сам.** После изменений запусти `pnpm typecheck && pnpm lint && pnpm test`. Не говори «готово», пока проверки не зелёные.
4. **Тесты обязательны** для бизнес-логики: напоминания, правила вакцинации, синхронизация, парсинг OCR.
5. **Не трогай без спроса:** миграции, которые удаляют данные; `.env*`; настройки сторов и подписок; продакшн-БД.
6. **Документируй решения.** Значимый выбор (библиотека, схема, паттерн) — новый файл `docs/adr/NNNN-название.md`.
7. **Обнови ROADMAP.md**: отметь выполненное `[x]` в конце задачи.

## Код
- TypeScript strict, без `any`. Валидация на границах — zod (одни схемы для API, мобильного клиента и OCR).
- Код, комментарии, коммиты — на английском. Тексты UI — через i18n, ключи на английском, язык по умолчанию украинский (`uk`), второй — `en`.
- Мобильное приложение — структура по фичам: `src/features/<feature>/{api,hooks,components,store}.ts`.
- Компоненты UI только из `src/shared/ui` (дизайн-система). Цвета и отступы — из токенов, без хардкода.
- Даты: хранить в UTC, показывать в `Europe/Kyiv`. Библиотека — date-fns.
- Коммиты: Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`).

## Доменные правила (важно)
- **Медицинская история владельца бесплатна и никогда не блокируется пейволом**, даже при окончании подписки.
- У каждой медзаписи есть `source`: `manual` | `ocr` | `clinic`, и версия. Записи OCR создаются только после подтверждения пользователем.
- AI-сводки не ставят диагнозов: формулировка «обсудить с врачом», дисклеймер.
- Медкарта, напоминания и QR-паспорт работают офлайн (блэкауты). Карта и события — онлайн.
- Геолокация питомца в MVP — только трек прогулки при открытом приложении.
- Документы хранятся в приватном бакете, доступ — только по подписанным ссылкам с коротким сроком.

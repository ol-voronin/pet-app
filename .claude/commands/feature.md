Задача: $ARGUMENTS
(если пусто — возьми первый незакрытый пункт из docs/ROADMAP.md)

Порядок:
1. Прочитай CLAUDE.md, связанные разделы docs/ и существующий код по теме.
2. Составь план: файлы, изменения схемы, тесты, риски. Задай вопросы, если требования неясны. Жди моего «ок».
3. Создай ветку `feat/<кратко>`.
4. Реализуй небольшими шагами. Сначала тесты для бизнес-логики.
5. Запусти `pnpm typecheck && pnpm lint && pnpm test`. Исправляй, пока не станет зелёным.
6. Если менялся UI — опиши, что проверить руками на устройстве (iOS и Android).
7. Отметь пункт в docs/ROADMAP.md, при значимом решении — добавь ADR.
8. Сделай коммит (Conventional Commits) и открой PR с описанием: что сделано, как проверить, что не вошло.

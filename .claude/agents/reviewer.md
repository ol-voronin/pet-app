## Когда ты запущен по расписанию (роль в команде, `docs/TEAM.md`)

Подпись в GitHub: `**[reviewer]**`. За один запуск пройди все открытые PR в `main`, кроме PR из форков
(им ставь `needs-owner` и ничего не запускай).

Для каждого PR:
1. Если на последний коммит уже есть твой вердикт и новых ответов нет — пропусти.
2. Возьми ветку, прочитай diff против `main`, запусти `pnpm typecheck && pnpm lint && pnpm test`. Пройди список выше.
3. Прочитай ответы разработчика на прошлые находки. Убедил — сними находку. Не убедил — объясни один раз; после
   второго круга без согласия поставь `decision` и оформи вопрос владельцу по `docs/TEAM.md`.
4. Оставь один комментарий-вердикт: `**[reviewer]** APPROVE <sha>` или `**[reviewer]** CHANGES <sha>` и находки.
5. Влей PR (squash), когда CI зелёный, есть твой `APPROVE` на последний коммит и нет меток `decision`, `needs-owner`.
   PR, который трогает список «Всегда к владельцу», не вливай — `decision`.

Код в чужом PR не правишь. Открытых PR нет — заверши запуск молча.

# Architecture

## Принципы
- Модульный монолит на TypeScript. Модули изолированы, чтобы позже вынести любой в сервис.
- Одна БД (PostgreSQL + PostGIS). Тяжёлая работа — в воркерах через очередь.
- Блэкауты: в MVP медкарта без сети читается (последняя загруженная), напоминания локальные; запись без сети — после MVP. Карта и события — онлайн.
- Хостинг в ЕС (GDPR, устойчивость), бэкапы в двух регионах.

## Компоненты
```
apps/mobile (Expo) ─┐
apps/web (Next.js) ─┼─► apps/api (REST + OpenAPI) ─► Postgres+PostGIS (Neon)
admin (Directus)  ──┘          │                    ├► Object Storage (документы, фото)
                               └► Redis/BullMQ ─► workers ─► LLM/OCR, FCM/APNs, Viber/SMS
```

## Модули API
| Модуль | Ответственность |
|---|---|
| auth | OTP по телефону (Viber → SMS fallback), Apple/Google (`auth_identities`), JWT access + refresh-сессии, роли |
| pets | Питомцы, семейный доступ (owner/editor/viewer, приглашения по ссылке), чип, № госреестра, фото и герой «аватар / фото» |
| avatar | Параметры аватара, автосборка по виду и породе, рендер (в приложении или на сервере — ADR-0007) |
| health | Медзаписи: vaccination, treatment, visit, lab, medication, note, weight; source + version + история версий |
| documents | Загрузка по presigned URL; файлы как есть (`stored`) и сканы; пайплайн OCR, извлечённые поля, лимит сканов |
| reminders | Правила-графики и произвольные напоминания, действие по типу («Записаться» / «Сделано»), планировщик, пуши |
| places | Точки карты, гео-поиск, тайлы; свои метки (личные / публичные) и очередь модерации; claim и отзывы (V2) |
| events | V2: события, RSVP, билеты, чек-ин |
| payments | V2: эквайринг (mono/WayForPay), RevenueCat webhooks, пРРО (Checkbox) |
| partners | V3: публичный API и вебхуки для CRM клиник, OAuth2 |

## Пайплайн распознавания документа
1. Клиент: сканер (VisionKit / ML Kit) → сжатие ~1600 px → `POST /documents` → presigned URL → загрузка в приватный бакет.
2. API ставит задачу `ocr.extract` в очередь.
3. Воркер: мультимодальная LLM со строгой JSON-схемой (zod → JSON Schema) → поля + confidence.
4. Нормализация препаратов и вакцин по справочнику (`packages/shared/dictionaries`).
5. Статус `needs_review` → пуш пользователю → экран подтверждения → создание медзаписей с `source=ocr`.
6. Хранить: оригинал, сырой ответ модели, версию промпта/модели, итоговые записи.

## Мобильное приложение
- expo-router (табы MVP: Карта · Питомцы · Мероприятия · Профиль; «Мероприятия» — заглушка «скоро», события — V2), TanStack Query, Zustand.
- Дизайн-система в `src/shared/ui`, токены — `HANDOFF.md` §5 (черновик, светлая тема).
- Офлайн в MVP: только чтение — кэш TanStack Query сохраняется на устройстве (медкарта, QR-паспорт, PDF). Локальная база, очередь изменений и синхронизация — после MVP, ADR-0003 (PowerSync облако / self-hosted / своя).
- Карта: @maplibre/maplibre-react-native + свои тайлы одним файлом PMTiles с нашего сервера (ADR-0005); точки — из PostGIS. Нужна своя сборка, в Expo Go — список.
- Пуши: expo-notifications; локальные напоминания планируются на устройстве.
- Покупки: RevenueCat. Билеты: внешняя оплата через expo-web-browser.
- Наблюдаемость: Sentry, PostHog (EU).

## Инфраструктура
| Что | Где |
|---|---|
| БД | Neon (PostgreSQL + PostGIS), регион EU |
| API + воркеры | Выделенный сервер владельца в Hetzner Falkenstein (EU): Docker Compose, Caddy (HTTPS) — ADR-0009. Vercel — запасной staging |
| Вспомогательное | VPS владельца в Украине (adm.tools): кандидат для Directus-админки и резервных копий |
| Файлы | Neon Object Storage (Франкфурт), приватный бакет (ADR-0006) |
| Очередь/кэш | Redis на том же сервере (в `deploy/docker-compose.yml`), наружу не открыт |
| B2B-кабинет | Vercel |
| Сборки | EAS Build / Submit / Update |
| CI | GitHub Actions: typecheck, lint, test на каждый PR; сборка образа API и деплой из `main` по SSH |

## Безопасность
- Закон Украины о защите персональных данных + GDPR: отдельные согласия (геолокация, маркетинг), удаление аккаунта в приложении.
- RBAC на уровне API; аудит-лог доступа к медкарте.
- QR для клиники — временный токен (24 ч), только чтение, краткая карта.
- Секреты — только в переменных окружения, никогда в репозитории.

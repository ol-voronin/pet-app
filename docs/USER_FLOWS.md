# User flows (MVP)

Тексты кнопок — на украинском, как в приложении. Кто эти люди — в `docs/PERSONAS.md`.
Объём MVP задаёт `docs/PRD.md`; этот файл показывает, как функции складываются в путь пользователя.

## 1. Онбординг
**Главный путь.** Вход (телефон и код или Apple/Google) → «Додайте улюбленця» → скан ветпаспорта → проверка полей →
аватар по виду и породе → первое напоминание → запрос пушей → дом.

**Ветки**
- «Вручну»: кличка, вид, дата рождения.
- «Пізніше»: сначала карта; скан предложим снова в пустой медкарте.

**Края**
- Код не пришёл — повтор через 60 с.
- Нечёткое поле подсвечено на экране проверки.
- Распознать не удалось — ручная форма.

## 2. Напоминание
**Главный путь.** Пуш → дело в «Найближче» → нужен специалист? → «Записатися» (звонок или место на карте) →
«На яку дату записалися?» → напоминание переносится на дату записи.

**Ветка.** Делается дома → «Зроблено» → для кого (можно нескольких) → запись у каждого питомца, следующее
напоминание — по правилу.

**Края**
- «Вже зроблено».
- «Відкласти» на завтра.
- Без сети пуш локальный.

## 3. «+»
**Главный путь.** Для кого (один или несколько) → что добавить → скан → сканы остались? → распознать и проверить.

**Ветки**
- Запись или напоминание вручную.
- Файл как есть: фото или PDF до 20 МБ.
- Сканы кончились — сохранить как файл, распознать позже. История не блокируется.

## 4. Визит к врачу
**Главный путь.** «Паспорт» → QR на 24 ч → врач открывает страницу без входа (фото, чип, вес, прививки, хроника,
анализы) → скан выписки → проверка → новое напоминание.

**Ветка.** Выписка пришла в Viber → «Завантажити файл».

**Края**
- У врача нет сети — PDF.
- QR истёк — новый.

## 5. Семья
**Главный путь.** «Запросити за посиланням» (роль: редактор или просмотр) → ссылка в Viber/Telegram → вход по
телефону → есть место? (Free: 2 участника на питомца) → видит всю историю, напоминания приходят обоим, у записи
есть автор.

**Предложение, не утверждено:** одно приглашение на всех питомцев сразу.

## 6. Карта
**Обзор.** Фильтр (клиники, аптеки, площадки, 24/7) → карточка (часы, адрес, дата проверки) → «Маршрут» или
«Подзвонити».

**Своя метка.** Долгое нажатие → название, категория, кто видит → «я и семья» сразу, «все» после модерации.

**Поиск** — кандидат, в объём MVP пока не входит (см. `docs/PRD.md`, «Кандидаты — ждут решения владельца»).
- Строка над картой → ввод названия, услуги («УЗД», «кінолог») или адреса → подсказки: места, категории, адреса,
  недавние.
- Место → сразу карточка. Адрес → карта сдвигается. Категория → пины и список по расстоянию → «відкрито зараз»,
  24/7, радиус.
- Ничего не найдено → шире радиус или «Додати свою мітку».
- Нечёткий поиск: опечатки, русская раскладка.
- Без сети — только недавние поиски.

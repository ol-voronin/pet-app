# Уроки и правила

Собрано 19.11.2026 по итогам первого дня: чат в claude.ai (продукт и дизайн) и сессии Claude Code (разработка).
Короткая версия правил стоит в `CLAUDE.md`; здесь — что именно случилось и почему правило появилось.

Новое правило добавляется сюда, когда ошибка повторилась или стоила больше часа. Устаревшее — удаляется.

## 1. Два потока работы не знали друг о друге

**Что случилось**

- Чат готовил handoff и писал «документы не обновлены, ADR открыты», когда Claude Code уже собрал монорепо, API и
  привёл документы в порядок. Часть предложенных «следующих шагов» была уже сделана.
- PR #7 из чата влит в `claude/fervent-bardeen-sr8xp2`. Это ветка по умолчанию на GitHub, но устаревшая: вся работа шла
  в `main`. Перенос потребовал отдельного PR #9 и синхронизации веток.
- В проекте claude.ai остались копии `PRD` и `HANDOFF` старее, чем в репозитории.

**Правила**

1. Источник правды — ветка `main` этого репозитория. Любая сессия, в чате или в Claude Code, начинает с
   `git fetch`, чтения `HANDOFF.md` и последних 15 коммитов `main`.
2. Перед открытием PR проверить, в какую ветку влиты последние PR. На default branch не полагаться.
3. Документы в проекте claude.ai — зеркало. Они обновляются из репозитория, не наоборот.
4. Решение по продукту, принятое в чате, попадает в `docs/PRD.md` одним PR в тот же день.

## 2. Handoff рос слоями

**Что случилось.** Версия 3 была версией 2 с новым разделом сверху и пометками «что устарело ниже». Читателю
приходилось сводить два слоя самому.

**Правило.** `HANDOFF.md` описывает текущее состояние. Устаревшее удаляется, история остаётся в git. Блок «что
изменилось» — не больше пяти строк.

## 3. Ограничения владельца всплывали поздно

**Что случилось**

- «Сейчас всё должно быть бесплатно» прозвучало после того, как ADR-0006 выбрал платное хранилище.
- «Делай сам, не зацикливай на мне» владельцу пришлось повторять в разных сессиях.

**Правила**

1. Ограничения владельца стоят первым блоком в `CLAUDE.md`.
2. Перед выбором любого сервиса проверить цену и нужна ли банковская карта.

## 4. Деплой чинили по одной ошибке за раз

**Что случилось.** По записи в handoff v3, деплой API на Vercel упирался в три ошибки подряд: не найден entrypoint,
`ERR_MODULE_NOT_FOUND` для пакетов воркспейса, `ERR_REQUIRE_ESM`. Каждая обнаруживалась только после отправки.

**Правило.** До PR с деплоем собрать и запустить продакшн-сборку локально так же, как это делает хостинг: та же версия
Node, запуск собранного entry, пакеты воркспейса отдают `dist`. В PR писать, что именно было запущено.

## 5. Объём MVP вырос за один вечер

**Что случилось.** Добавились свои метки с модерацией, загрузка файлов, произвольные напоминания и конструктор
аватара; ещё предложен «дом» на нескольких питомцев. Срок пересчитали уже после: 16 недель превратились примерно в 21.

**Правило.** Каждое «давай добавим» получает оценку в неделях и ответ «MVP или вторая версия» до того, как попадает
в `docs/PRD.md`.

## 6. Дизайн сделан в три прохода вместо одного

**Что случилось**

- Первая цветная проба вышла шаблонной: стиль выбирался до того, как владелец показал референсы.
- Экраны проектировались на одного питомца. У владельца их трое, и главный экран не отвечал на его вопрос «что мне
  сделать на этой неделе и кому».
- Автор макетов ни разу не видел их в рендере. Проблемы находил владелец по скриншоту.
- Набор Fluent Emoji отброшен: чужая иллюстрация делает продукт похожим на шаблон.

**Правила**

1. До первого цветного макета получить от владельца 5–8 референсов и согласовать цвет и шрифт.
2. Каждый экран проверять на сценарии: три питомца (собака и два кота), двое взрослых, одно просроченное дело.
3. Автор смотрит рендер или просит скриншот до слова «готово». Если проверить нельзя — так и написать.
4. Чужие наборы иллюстраций не использовать.

## 7. Публичный репозиторий

**Что случилось.** Репозиторий публичный, хотя план предполагал приватный. В нём лежат стратегия, цены, идентификаторы
проектов Vercel, Neon и Expo, адрес staging и сведение о том, что staging принимает фиксированный код входа.

**Правила**

1. Секреты — только в переменных окружения. Это соблюдается, так и оставить.
2. Пока действует фиксированный код входа, в staging нет реальных данных.
3. До первых реальных пользователей: приватный репозиторий либо отключённый фиксированный код. Решение за владельцем.
4. Личные сведения о владельце в репозиторий не писать.

## 8. Задержки и «лаги»

**Что случилось**

- Один чат в claude.ai шёл весь день: десятки картинок и вызовов инструментов. Чем длиннее чат, тем медленнее ответы
  и тем больше теряется по дороге.
- Долгие операции без единого сообщения выглядят как зависание.

**Правила**

1. Одна тема — один чат или одна сессия. В Claude Code — `/clear` перед новой задачей.
2. Операция дольше минуты — сразу сказать, что происходит и сколько ждать.
3. Новый чат в claude.ai начинать так: «Подключи репозиторий `ol-voronin/pet-app`, прочитай `HANDOFF.md` и
   `docs/LESSONS.md` из `main`. Задача: …».

## 9. Первый запуск на телефоне нашёл то, чего не видели тесты

**Что случилось.** Экраны питомцев прошли тесты, сборку под iOS и Android и проверку API, но на телефоне владельца
таб «Улюбленці» был пустым и сбрасывал на карту.
- Запросы с токеном доходили до сервера и получали 200, а приложение считало их ошибкой: библиотека клиента проверяла
  ответ через `instanceof Response`, а на телефоне ответ создаёт платформа, и проверка не проходила.
- Из-за этой «ошибки» экран с табами пересоздавался при каждой перезагрузке списка и открывал первый таб.
- Причину нашли по логам сервера на Vercel (запросы идут парами, все 200), а не по коду.

**Правила**
1. «Собирается» и «тесты зелёные» — не «работает на телефоне». Пока экран не открыт на устройстве, в отчёте писать
   «на устройстве не проверено», а первую проверку на телефоне делать до следующей фичи.
2. Когда приложение ведёт себя странно, сначала смотреть логи сервера: дошёл ли запрос и какой был ответ.
3. Навигатор (табы) не пересоздавать из-за состояния загрузки данных: решение «что показать» принимается один раз.

## 10. Что работает и что нет

- **Локальные компании.** Веб-поиск не нашёл три клиники из четырёх. Google Maps в браузере нашёл все с первого раза.
- **Mobbin.** На бесплатном аккаунте видно 5 экранов на запрос. Быстрее всего открывать прямую ссылку
  `mobbin.com/search/apps/ios?content_type=screens&q=<приложение>`.
- **Аватары.** Blender ставится как модуль Python (`pip install bpy`) и рендерит на процессоре без видеокарты.
- **Ссылки claude.ai.** Claude Code их не открывает. Всё нужное для разработки должно лежать в репозитории.
- **Слияние PR из чата.** Без явной команды владельца оно блокируется защитой. Владельцу достаточно написать «Merge».

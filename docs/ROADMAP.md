## Неделя 0 — Подготовка (делает владелец продукта, без кода)
- [x] Приватный репозиторий на GitHub, в корень скопирован этот набор
- [ ] Установлены Node LTS, pnpm, Git, Claude Code, EAS CLI, Android Studio (и Xcode, если есть Mac)
- [ ] Аккаунты: Expo, Apple Developer ($99/год), Google Play Console ($25), Neon, Cloudflare R2, Upstash, Sentry, PostHog
- [ ] MCP в Claude Code: GitHub, Neon, Vercel, Figma, Sentry, Context7
- [ ] Figma: онбординг со сканом, экран подтверждения OCR, медкарта, профиль питомца, карта (хотя бы вайрфреймы)
- [ ] Начат сбор реальных ветдокументов для проверки OCR (цель — 20+)
- [ ] Список 5–10 клиник Харькова для пилота

## Этап 0 — Фундамент (неделя 1–2)
- [x] Монорепо: pnpm + Turborepo, apps/mobile, apps/api, packages/shared, packages/db
- [ ] TypeScript strict, ESLint, Prettier, общие tsconfig
- [ ] GitHub Actions: typecheck + lint + test на PR
- [ ] Neon: проект, ветка dev, PostGIS включён; Drizzle подключён, первая миграция
- [ ] API: Fastify, health-check, OpenAPI, генерация клиента в packages/shared
- [ ] Mobile: Expo + expo-router, development build, табы-заглушки, i18n (uk/en)
- [ ] Дизайн-токены и базовые компоненты UI (Button, Input, Card, ListItem, Sheet)
- [ ] Sentry в mobile и api

## Этап 1 — Аккаунт и питомцы (неделя 3–4)
- [ ] Auth: OTP (мок-провайдер в dev), JWT + refresh, SecureStore
- [ ] Sign in with Apple / Google
- [ ] CRUD питомцев, фото в R2 через presigned URL
- [ ] Семейный доступ: приглашение по ссылке, роли

## Этап 2 — Медкарта (неделя 5–7)
- [ ] Схема health_records + версии, API CRUD
- [ ] Экраны медкарты: таймлайн, фильтр по типам, карточка записи
- [ ] Формы для каждого типа записи
- [ ] Офлайн: expo-sqlite + PowerSync, очередь изменений, разрешение конфликтов
- [ ] Справочники вакцин и препаратов (seed)

## Этап 3 — Скан и AI (неделя 8–10)
- [ ] Сканер документов, сжатие, загрузка, статусы
- [ ] Воркер OCR: LLM + JSON-схема, нормализация по справочникам
- [ ] Экран подтверждения: поля, confidence, увеличенный фрагмент оригинала
- [ ] Набор тестовых документов (20+ реальных фото ветпаспортов и справок) + eval-скрипт точности
- [ ] Лимит 5 сканов в месяц для Free (счётчик, без блокировки истории)

## Этап 4 — Напоминания (неделя 11)
- [ ] Правила: ревакцинация, обработки, курс лекарств

- [ ] Запрос разрешения на пуши в момент ценности

- Пересчёт 19.11.2026: +0,5 нед. — загрузка файлов, +1 — произвольные напоминания и действия по типу,
  +1 — свои метки и модерация, +2 — аватар (без учёта доводки 3D-форм художником), +0,5 — запас на онбординг
  с двумя путями. Таб «Мероприятия» в MVP — только заглушка «скоро будет» (−0), события — V2.
- Пересчёт 20.11.2026 (решения владельца, `docs/PRD.md`): +1,5 — поиск на карте по названию, категории и адресу,
  +0,5 — QR «только прививки», +0,5 — крупный системный шрифт и слабые Android.
- Пересчёт 20.11.2026, issue #36: −2 — офлайн-запись медкарты (ADR-0003, локальная база, очередь, конфликты) ушла
  после MVP, +0,5 — чтение без сети из сохранённого кэша, +0,5 — свой сервер (Docker, HTTPS, деплой, Sentry).

**Порядок работ (решение владельца 20.11.2026): сервер → карта → медкарта онлайн → скан → напоминания → аватар → бета.**

они не менялись: после Этапа 1 идут 1b и 5, потом 2.

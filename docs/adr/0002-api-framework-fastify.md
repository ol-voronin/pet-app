# 0002 — Фреймворк API: Fastify

- Статус: Принято
- Дата: 2026-11-19

## Контекст
Нужен REST API с OpenAPI (для генерации клиента в `packages/shared`), валидацией через zod,
модульной структурой (auth, pets, health, documents, reminders, places…). Команда 2–3 человека.

## Варианты
1. **Fastify 5** — лёгкий и быстрый, плагины как модули, OpenAPI через `@fastify/swagger`,
   zod-схемы маршрутов через type provider. Минус: структуру модулей держим соглашениями сами.
2. **NestJS** — строгая структура (модули, DI, декораторы), OpenAPI из коробки. Минусы: больше
   шаблонного кода и порог входа; декораторы плохо сочетаются с «одни zod-схемы на всё».
3. **Hono** — минималистичный, хорош для edge; экосистема плагинов для Node-сервера беднее.

## Решение
Fastify 5. Каждый модуль API — Fastify-плагин в `apps/api/src/modules/<module>`;
схемы запросов/ответов — zod из `packages/shared`, из них же генерируется OpenAPI.

## Последствия
- Соглашения о структуре модулей фиксируем в `apps/api/README` на шаге «API».
- Вынос модуля в отдельный сервис — перенос плагина, без переписывания.

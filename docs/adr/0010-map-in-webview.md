# 0010 — Карта в WebView (MapLibre GL JS), тайлы OpenFreeMap до своего сервера

- Статус: Принято (20.11.2026; владелец попросил карту в приложении сейчас — «Карта не отображается. Надо делать по дизайнам»)
- Уточняет ADR-0005: движок тот же — MapLibre, меняется способ встроить его и временный источник тайлов.

## Контекст
По ADR-0005 карта — нативный `@maplibre/maplibre-react-native` с тайлами одним файлом PMTiles на нашем сервере.
Обоим условиям нужен владелец: сервер в Hetzner ещё не запущен, своей сборки приложения нет — владелец смотрит
приложение в Expo Go, а в Expo Go нативной карты не бывает. Пока таб «Карта» был списком без карты.

## Варианты
1. **Ждать сервер и свою сборку.** Карты нет ещё неопределённое время.
2. **`react-native-maps`** (есть в Expo Go). На Android это Google Maps: для своей сборки нужен ключ Google Cloud
   с банковской картой; iOS и Android выглядят по-разному; стиль под макеты не настроить. Не проходит по «без карты».
3. **MapLibre GL JS в WebView — выбрано.** `react-native-webview` есть в Expo Go и в любой сборке, поэтому код один.
   Тайлы — публичный OpenFreeMap: бесплатно, без ключей, регистрации и лимитов, коммерческое использование
   разрешено (openfreemap.org, проверено 20.11.2026), данные — OpenStreetMap, украинские подписи есть (`name:uk`).

## Решение
- Страница карты собирается в приложении (`apps/mobile/src/features/places/map/mapHtml.ts`): MapLibre GL JS 5.24.0
  с jsDelivr с проверкой целостности (SRI), базовый стиль OpenFreeMap Positron, перекрашенный под токены (`mapColors`),
  подписи по-украински, POI базовой карты скрыты — на карте только наши точки.
- Пины, кластеры, выбранная точка с расстоянием и точка «я» рисуются слоями MapLibre внутри страницы.
- Приложение и страница общаются JSON-сообщениями (`protocol.ts`); всё, что приходит со страницы, проверяется zod.
  На страницу уходят только координаты, категория и id — без названий и адресов.
- Источник стиля — `app.json` → `extra.mapStyleUrl`; пусто — OpenFreeMap. Когда заработает свой сервер, туда ставится
  адрес стиля с нашим файлом PMTiles (ADR-0005), код не меняется.
- Атрибуция видна всегда, в нижней панели: «OpenFreeMap © OpenMapTiles · дані © OpenStreetMap».

## Последствия
- Карта работает в Expo Go уже сейчас; своя сборка для карты больше не обязательна.
- Запросы тайлов уходят с телефона напрямую на `tiles.openfreemap.org` (видны IP и область карты). Cookies и учётных
  записей там нет. После переезда на свой сервер это уходит.
- OpenFreeMap — бесплатный проект без SLA. Упал — страница сообщает об ошибке, приложение показывает «Карта не
  завантажилась», список мест под картой продолжает работать.
- Нужен WebGL2 в WebView (MapLibre GL JS 5). Современные iOS и Android его дают; на старом Android без WebGL2 будет то
  же сообщение и список.
- Производительность на слабом Android не измерена. Если карта будет тормозить — вернуться к нативному MapLibre
  (ADR-0005): данные и экран уже разделены, меняется только `MapView`.

# 0006 — Хранилище файлов: Cloudflare R2 или Hetzner Object Storage

- Статус: Принято (19.11.2026, по ответу владельца)
- Дата: 2026-11-19

## Контекст
Нужен приватный бакет для документов, фото питомцев и рендеров аватаров. Доступ только по
подписанным ссылкам с коротким сроком (`CLAUDE.md`). Хранение в ЕС (`ARCHITECTURE.md`: GDPR).
Объём MVP небольшой: при 5 000 пользователей × ~20 файлов × ~1,5 МБ ≈ 150 ГБ за первый год.
У владельца уже есть «Cloud storage 1 TB» у Hetzner. Какой это продукт, нужно уточнить: **Storage Box**
работает только по SFTP/SMB/WebDAV, без S3 и без подписанных ссылок, поэтому для приложения он не подходит.
Подходит только **Hetzner Object Storage**.

## Варианты

### 1. Cloudflare R2 (EU jurisdiction)
- Цена: $0,015 за ГБ в месяц, первые 10 ГБ бесплатно; **исходящий трафик бесплатный**;
  операции: $4,50 за млн записей, $0,36 за млн чтений.
- Плюсы: на объёмах MVP почти бесплатно (150 ГБ ≈ $2 в месяц); S3 API и presigned URL;
  бакет можно привязать к юрисдикции ЕС; при желании — CDN Cloudflare для публичных рендеров аватаров.
- Минусы: ещё один поставщик и аккаунт; данные в инфраструктуре американской компании (с юрисдикцией ЕС).

### 2. Hetzner Object Storage (Германия / Финляндия)
- Цена: базовый тариф ≈ €6,49 в месяц без НДС, в него входят 1 ТБ хранения и 1 ТБ исходящего трафика;
  сверх этого ≈ €1 за ТБ трафика. Цены на 2026 год не перепроверены — сверить на странице Hetzner перед решением.
- Плюсы: европейский поставщик, дата-центры в ЕС; один счёт с серверами/VPS, если API будет у Hetzner;
  фиксированная цена, лимит 1 ТБ закрывает MVP с большим запасом.
- Минусы: платим базовый тариф с первого дня, даже при 1 ГБ; нет встроенного CDN.

### 3. Storage Box (уже есть у владельца)
- Не подходит как основное хранилище: нет S3 API и подписанных ссылок. Можно использовать для бэкапов БД.

## Решение (предложение)
Код пишем против **S3 API** (`@aws-sdk/client-s3` + `@aws-sdk/s3-request-presigner`), провайдер задаётся
переменными окружения (`S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`, ключи). Переезд между R2 и Hetzner — это смена
конфигурации и копирование бакета, без изменений кода.

Для MVP предлагаю **Hetzner Object Storage**, если у владельца уже есть проект в Hetzner Cloud (один поставщик,
ЕС, фиксированная цена). Если «Cloud storage 1 TB» — это Storage Box и нового договора с Hetzner заводить
не хочется — **Cloudflare R2** с юрисдикцией ЕС: на объёмах MVP почти бесплатно.

## Ответ владельца (19.11.2026)
- «Cloud storage 1 TB» — это **Storage Box** BX11 (Falkenstein): только SSH/SFTP, используется другим проектом.
  Для приложения не подходит; можно завести подаккаунт для бэкапов БД.
- У владельца есть **проект Hetzner Cloud** (там доступен Object Storage) и выделенный сервер в Falkenstein.
- Поэтому по правилу выше берём **Hetzner Object Storage**, регион `fsn1`: бакет `pet-app-files` (приватный)
  создаёт владелец, ключи доступа — в секреты окружения.

## Последствия
- Модуль `documents` и загрузка фото питомцев используют общий S3-клиент из `apps/api`.
- Подписанные ссылки: загрузка — 10 минут, чтение — 15 минут. Лимит 20 МБ и список MIME-типов
  проверяются в API до выдачи ссылки на загрузку.
- Нужны ключи доступа к бакету: владелец добавляет их в секреты окружения (не в репозиторий).

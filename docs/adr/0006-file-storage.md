# 0006 — Хранилище файлов: Neon Object Storage

- Статус: Принято (19.11.2026, пересмотрено под ограничение владельца «бесплатно или по моей подписке»)
- Дата: 2026-11-19
- Заменяет прежнее решение «Hetzner Object Storage» (платно с первого дня, ≈ €6,49 в месяц).
- Цены проверены 19.11.2026 по документации вендоров (ссылки внизу).

## Контекст
Нужен приватный бакет для документов, фото питомцев и рендеров аватаров. Доступ только по
подписанным ссылкам с коротким сроком (`CLAUDE.md`). Хранение в ЕС (`ARCHITECTURE.md`: GDPR).
Файл до 20 МБ. На старте объём — единицы ГБ; оценка на первый год — до 150 ГБ
(5 000 пользователей × ~20 файлов × ~1,5 МБ).

Ограничение владельца: сейчас всё бесплатно или в рамках уже оплаченных подписок. У владельца есть Neon.

## Варианты

### 1. Neon Object Storage — выбрано
S3-совместимое хранилище внутри проекта Neon `pet-app` (Франкфурт). На ветке `dev` уже включено.
- Цена: на Free — 5 ГБ на проект бесплатно; на платном плане — $0,023 за ГБ в месяц, за операции не берут
  (10 ГБ ≈ $0,23; счета меньше $0,50 Neon не выставляет). Исходящий трафик — из общей квоты проекта.
- Плюсы: без нового аккаунта и карты; хранилище ветвится вместе с БД (`dev` и `main` не пересекаются);
  S3 API, presigned URL; приватный бакет по умолчанию.
- Минусы: продукт молодой, реализована часть S3 API; возможен `503 SlowDown` (нужен повтор);
  файлы и БД у одного вендора; restore БД файлы не откатывает; отдельных бэкапов файлов нет.

### 2. Cloudflare R2 (EU jurisdiction) — запасной
- Цена: 10 ГБ бесплатно, дальше $0,015 за ГБ в месяц; исходящий трафик бесплатный.
- Минусы: новый аккаунт и банковская карта; для `dev` и прод — отдельные бакеты вручную.

### 3. Hetzner Object Storage
- Цена: ≈ €6,49 в месяц без НДС (1 ТБ хранения и 1 ТБ трафика). Платно с первого дня — не проходит по ограничению.

### 4. Storage Box владельца (BX11)
- Не подходит: только SSH/SFTP, нет S3 API и подписанных ссылок. Годится для бэкапов.

## Решение
**Neon Object Storage**, приватный бакет `pet-app-files` на каждой ветке Neon (`dev`, позже `main`).

Код пишем против **S3 API** (`@aws-sdk/client-s3` + `@aws-sdk/s3-request-presigner`), провайдер задаётся
переменными окружения (`S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`, ключи; для Neon — `forcePathStyle`).
Переезд на R2 — смена конфигурации и копирование бакета, без изменений кода.

## Последствия
- Модуль `documents` и загрузка фото питомцев используют общий S3-клиент из `apps/api`.
- Подписанные ссылки: загрузка — 10 минут, чтение — 15 минут. Лимит 20 МБ и список MIME-типов
  проверяются в API до выдачи ссылки на загрузку. В БД хранится только `storage_key`.
- Ключи доступа — в секретах окружения, не в репозитории.
- При росте за 5 ГБ на Free появится плата ($0,023 за ГБ) — пересмотреть тогда: остаться или уйти на R2.
- До открытой беты нужен план бэкапа файлов (например, выгрузка на Storage Box владельца).

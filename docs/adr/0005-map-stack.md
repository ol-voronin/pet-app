# 0005 — Карта: MapLibre и свои тайлы одним файлом PMTiles

- Статус: Принято (предложение владельца в issue #36; сравнение ниже его подтверждает)
- Дата: 2026-11-20
- Цены, лимиты и версии проверены 20.11.2026 по страницам вендоров (ссылки внизу). Что проверить не удалось — в конце.

## Контекст
Нужна подложка карты (векторные тайлы и стиль) с подписями на украинском. Точки — наши, из PostGIS
(импорт OSM и ручная проверка), подложка их не содержит. Ещё нужен поиск по адресу (`docs/PRD.md`, решения от 20.11).
Ограничение владельца: сейчас всё бесплатно, без новых счетов. Продукт коммерческий. Сервер в Hetzner уже есть (ADR-0009).

## Варианты

| | MapLibre + свой PMTiles | MapTiler Cloud Free | Mapbox |
|---|---|---|---|
| Цена сейчас | 0: файл лежит на нашем сервере | 0 | 0 до 25 000 активных в месяц |
| Лимит | нет (только диск и трафик сервера) | 5 000 сессий и 100 000 запросов тайлов в месяц; при превышении сервис встаёт до следующего месяца | дальше $4 за 1 000 активных |
| Карта для регистрации | не нужна | не нужна | без карты — только «demo access» с урезанными лимитами |
| Коммерческое использование | да (ODbL: подпись «© OpenStreetMap») | **нет**: Free — только некоммерческое и разработка | да |
| Первый платный шаг | — | Flex, $30 в месяц | по счётчику |
| Украинские подписи | да: `lang: "uk"` в `@protomaps/basemaps`, кириллица в шрифтах Noto есть | да (`name:uk`) | да в стилях Standard |
| Движок в приложении | MapLibre | MapLibre | только Mapbox SDK: условия запрещают другой способ доступа в мобильном приложении |
| Кто отвечает за доступность | мы | вендор | вендор |

- **MapTiler Free отпадает по условиям:** продукт коммерческий, а 100 000 тайлов — это несколько сотен активных
  пользователей; при превышении карта просто перестаёт работать.
- **Mapbox** бесплатен на старте, но это карта владельца в аккаунте, закрытый SDK и счёт, растущий с аудиторией.
  Перейти с него на MapLibre потом — переписать экран.
- **Свой PMTiles** — один файл, тайл-сервер не нужен: приложение читает куски файла обычными HTTP range-запросами.

## Решение
1. **Движок:** `@maplibre/maplibre-react-native` 11.x (только New Architecture, встроенный config plugin Expo).
   Кластеры — встроенные в `GeoJSONSource` (`cluster`, `clusterRadius`, `getClusterExpansionZoom`).
2. **Тайлы:** экстракт из ежедневной сборки Protomaps: `pmtiles extract https://build.protomaps.com/<дата>.pmtiles
   out.pmtiles --bbox=… --maxzoom=15`. Источник в стиле — `pmtiles://https://<наш сервер>/tiles/<файл>.pmtiles`.
3. **Объём для пилота — Харьковская область, ≈ 180 МБ** (z0–15). Вся Украина — ≈ 3,7 ГБ (оценка сверху, по прямоугольнику);
   это тот же скрипт с другой рамкой. Переходим на всю Украину, когда выходим за Харьков. Только город — ≈ 16–24 МБ:
   годится как файл для будущей офлайн-карты.
4. **Где лежит:** на нашем сервере, статикой через Caddy (range-запросы он умеет). Там же — шрифты и спрайты из
   `protomaps/basemaps-assets` и JSON стиля. Приватный бакет Neon не подходит: тайлы публичные.
5. **Стиль:** светлый `@protomaps/basemaps` с `lang: "uk"`, цвета подложки приглушаем под токены; пины — тёмные, наши.
6. **Атрибуция:** «© OpenStreetMap» на карте — обязательна.
7. **Поиск по адресу:** публичный Photon (`photon.komoot.io`) через наш API — кэш, пауза между запросами, привязка к
   центру карты. Параметр `lang` не передаём: `uk` он не принимает, а без него украинские адреса находит.
   Nominatim для подсказок нельзя — запрещено его правилами. Запасные: свой Photon на нашем сервере (дамп Украины
   269 МБ, обновляется раз в неделю) или Geoapify Free (3 000 запросов в день, без карты, коммерция разрешена).

## Последствия
- **Expo Go карту не покажет:** MapLibre — нативный модуль, нужна своя сборка (`eas build --profile development`,
  запускает владелец с Mac). В Expo Go таб «Карта» покажет список точек и объяснение, без падения.
- Версии: библиотека собирается на Expo 56 / RN 0.85, у нас Expo 58 / RN 0.88. Официальной поддержки нет, но есть
  отчёт о работе на этой связке. Первый шаг экрана карты — проверочная сборка.
- В документации обёртки PMTiles не описан (в ядре MapLibre Native он есть с Android 11.8 / iOS 6.10, в обёртке ядро
  новее). Если `pmtiles://` через `VectorSource` не заведётся — запасной путь без смены решения: `pmtiles serve`
  рядом с API отдаёт тот же файл обычными `z/x/y`.
- Доступность карты теперь наша забота: упал сервер — нет подложки. Точки при этом остаются списком.
- Обновление подложки — перезалить файл раз в несколько месяцев; дороги меняются медленно, точки живут в нашей БД.
- Публичный Photon — без гарантий и без числовых лимитов («разумное использование»). Одна проба русского запроса
  («Харьков Сумская 10») дала адрес в другой стране: нужна привязка к центру карты, а если качество не устроит —
  свой Photon (оценка: 1–2 ГБ диска и столько же памяти).
- Офлайн-карта в MVP не делается (`CLAUDE.md`: карта — онлайн). Файл города на 16–24 МБ оставляет эту дверь открытой.

## Не проверено
- Работа `pmtiles://` через обёртку на iOS и Android — только сборкой на устройстве.
- Кэширует ли MapLibre удалённые PMTiles (документация и changelog расходятся).
- Точный размер файлов: цифры посчитаны по каталогу сборки от 18.11.2026, не командой `pmtiles extract`.
- Свободное место на сервере владельца.
- Память и диск своего Photon для Украины — оценка по размеру дампа.
